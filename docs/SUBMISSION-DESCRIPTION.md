# Entry description

Fechamento Claro helps small-business owners and bookkeepers investigate settlement differences with original source-row evidence. The local Zetaris platform registers order, settlement and refund snapshots, reads their original rows and joins the totals through its official JDBC driver. Independent integer-cent rules verify every counted amount and quarantine conflicting IDs. Meterless Nightshift is the primary and only generative provider: a verified local Llama 3.1 8B model selects bounded H-MEM search, case inspection and completion tools. Only inspected findings can reach the answer; rules supply the returned amounts, citations and next checks. Actual receipts identify local model execution. Live scenarios demonstrate a R$10 unexplained shortfall, a duplicate-ID conflict and an order not yet due. Actual Cursor development review and resulting fixes are documented. Nineteen automated tests cover arithmetic, source consistency, dates, conflicts, retrieval and provider safeguards. The 2m27 edited demo uses real local captures with synthetic English narration. All data is fictional. No bank connection, payment movement, proven cause or production accuracy is claimed. GitHub Pages offers a browser preview; the complete engines run locally. Built solo by Bruno Fernandes, an Accounting graduate, inside the official build window.
